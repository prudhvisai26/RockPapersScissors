# Rock Paper Scissors Game 🎮✊📄✂️

A simple yet fun Rock-Paper-Scissors game built using **HTML**, **CSS**, and **JavaScript**.

## 🔗 Live Demo

Play it here: [Rock Paper Scissors Game](https://prudhvisai26.github.io/RockPapersScissors/)

---

## 🚀 Features

- Interactive gameplay with Rock, Paper, and Scissors options.
- Game consists of **5 rounds**, and the player with the highest score wins.
- Displays **computer choice**, **user points**, and **computer points**.
- Start and Reset buttons for controlled gameplay.
- Stylish UI with hover and click effects.

---

## 🧠 Game Rules

- Rock beats Scissors  
- Scissors beats Paper  
- Paper beats Rock  
- If both choose the same, both get 1 point  
- After 5 rounds, the winner is declared based on score.

## 🛠️ Technologies Used

## ▶️ Getting Started

1. Clone the repo:
```bash
git clone https://github.com/prudhvisai26/RockPapersScissors.git
```
2. Navigate to the project folder:
```bash
cd RockPapersScissors
```
3. Open index.html in your browser.

🧹 Reset Game
Click the Reset button to restart the game and play again!
